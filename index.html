Each train must pass through both blocks to reach its destination. P1 (Express 101, eastbound) enters Block A and then needs Block B. P2 (Freight 202, westbound) enters Block B and then needs Block A. Orange glow on the track = block occupied. A red signal = train must stop.

Four Conditions for Deadlock

0 / 4 conditions met
1
Mutual Exclusion

A track block can hold only one train at a time. Two trains can never occupy Block A or Block B together.

2
Hold and Wait

A train keeps its current block while waiting for the next one. P1 holds Block A and waits for Block B; P2 holds Block B and waits for Block A.

3
No Preemption

A block cannot be forcibly taken from a train. It is released only when the train clears it.

4
Circular Wait

P1 → Block B (R2) → P2 → Block A (R1) → P1. Each train waits for the other, so nobody can move.

Event Log

    Recovery Method

    • Detect a cycle in the wait-for graph (P1 waits for P2, P2 waits for P1).
    • Choose a victim train to terminate, or a block to preempt.
    • Break one of the four conditions: Circular Wait or No Preemption.
    • Resume normal train operation.
