Four Conditions for Deadlock

0 / 4 conditions met
1
Mutual Exclusion

A resource can be used by only one process at a time. Only one robot can use the welding tool or the paint sprayer.

2
Hold and Wait

A process holds one resource while waiting for another. P1 holds R1 and waits for R2; P2 holds R2 and waits for R1.

3
No Preemption

A resource cannot be forcibly taken away. It is released only when its process finishes with it.

4
Circular Wait

Processes wait in a cycle: P1 → R2 → P2 → R1 → P1. Nobody can move.

Event Log

    Recovery Method

    • Detect a cycle in the wait-for graph (P1 waits for P2, P2 waits for P1).
    • Choose a victim process to terminate, or a resource to preempt.
    • Break one of the four conditions: Circular Wait or No Preemption.
    • Resume normal factory operation.
